# テーブル領域推定 要件定義書

## 目的

Data001/Data002 のテーブルA・テーブルCに向かう軌跡を対象に、軌跡からテーブル周辺の点を抽出し、クラスタリングによってテーブル領域を代表する点を推定する。

## 対象データ

- 使用データ: Data001, Data002
- 対象軌跡: テーブルA, テーブルCに向かう軌跡
- 入口: 推定済みと仮定し、原点を入口とする

## 分析方針

まず、1本の軌跡を複数のセグメントに分割する。分割後、それぞれのセグメントを通路セグメントまたはテーブル周辺セグメントに分類する。

テーブル領域の推定には、全軌跡の点をそのまま使わない。通路を歩いている点を除外し、テーブル周辺セグメントに含まれる点群または代表点だけをクラスタリングに用いる。これにより、クラスタリング対象をテーブル周辺の行動が現れた点に限定し、テーブル領域の代表点を推定する。

## セグメント分割

セグメント分割は、1本の軌跡に対して行う。1本の軌跡は、複数の連続したセグメントから構成される。

分割条件は以下とする。

- 進行方向が45度以上変化した場合
- 速度変化が起こった場合
  - 直前数歩の平均速度と比較して、現在の速度が低下した場合
  - 直前数歩の平均速度と比較して、現在の速度が上昇した場合

ただし、セグメントが細かくなりすぎないように、最小セグメント長と最小境界間隔を設ける。

現在の実装では、最小セグメント長と最小境界間隔を3歩としている。速度変化は、直前数歩の平均速度に対する変化率で判定する。

## セグメント分類

分割した各セグメントを、ルールベースで通路セグメントまたはテーブル周辺セグメントに分類する。

通路セグメントの特徴:

- 速度が比較的一定
- 大きな減速や停止に近い挙動が少ない
- 単に通路形状に沿って曲がるだけの場合がある

テーブル周辺セグメントの特徴:

- 今までの速度よりも低下する
- 低速状態または停止に近い状態が続く
- 速度のばらつきが大きくなる
- 上記の速度系特徴から求めたテーブル周辺セグメントの近くで、席の奥側へ向かうために曲がる動作が見られる

重要な条件として、「曲がっただけ」ではテーブル周辺とは判定しない。テーブル周辺分類では、減速、低速、停止に近い挙動、または減速後の行動変化を根拠とする。

また、セグメント内に1点だけ強い減速があるだけでは、その長いセグメント全体をテーブル周辺とは扱わない。現在の実装では、セグメント内で減速点または低速点が一定割合以上含まれる場合にテーブル周辺と判定する。

曲がり動作については、減速と曲がりが同時に起きることを必須条件にはしない。まず、速度低下、低速状態、速度ばらつきからテーブル周辺らしい核セグメントを求める。そのうえで、その核セグメントに空間的に近い曲がりセグメントをテーブル周辺セグメントとして追加する。これにより、通路形状による単なるカーブをテーブル周辺として誤検知しにくくする。

## クラスタリング

クラスタリングには、テーブル周辺セグメントから抽出した点のみを用いる。通路セグメントの点はクラスタリング対象に含めない。

クラスタリング結果から、テーブルA・テーブルCそれぞれについて代表点を求める。代表点は、テーブル周辺点群のクラスタ中心として扱う。

## 可視化要件

軌跡の可視化では、以下を確認できるようにする。

- 1本の軌跡がどのようにセグメント分割されたか
- セグメントごとの色の変化
- 分割後、どのセグメントが通路か、どのセグメントがテーブル周辺か
- テーブル周辺セグメントには「テーブル周辺」ラベルを表示する
- 減速点、速度変化、方向変化が確認できる
- クラスタリングによって求めた推定点が確認できる
- 全対象軌跡を1つの座標平面上に重ねた図を出力する
- 各軌跡ごとに、分割・分類・速度特徴量を確認できる診断図を出力する

## 出力

- セグメント一覧CSV
- 速度特徴量CSV
- 速度特徴量サマリCSV
- テーブル周辺セグメント点CSV
- クラスタ済みテーブル周辺点CSV
- 推定テーブル代表点CSV
- 全対象軌跡を1平面に重ねたセグメント分割図
- テーブル代表点の可視化図
- 各軌跡ごとの3段診断図
